# Lilith AI MOD Beta.4 — インストールと更新

[繁體中文](INSTALLATION.md) · [English](INSTALLATION_EN.md)

## インストール前

64 ビット版 Windows を使用し、まず Steam からゲーム本体をインストールして、正常に起動することを確認してください。旧アーキテクチャー／クローズドテスト版を使った方は、先に下記の旧データ削除を行います。ゲームとコントロールセンターは通知領域のものも含めて終了してください。

ダウンロード分だけでなく、展開・インストール・一時ファイル用の空き容量も必要です。実行環境は同梱されているため、開発 SDK やシステム Python を別途インストールする必要はありません。ローカル音声の速度や使用メモリは、ハードウェア、ドライバー、設定によって変わります。

## インストール／更新手順

1. `Lilith-AI-Mod-1.0.0-Beta.4.zip` を展開します。圧縮ファイル内から直接セットアップを実行しないでください。
2. `Lilith-AI-Mod-1.0.0-Beta.4-Setup.exe` と `Lilith-AI-Mod-1.0.0-Beta.4-Main.zip` を同じフォルダーに置きます。**Main.zip は展開しません。**
3. 音声依存 ZIP を使用する場合は展開せず、Setup.exe と同じフォルダーか、その一つ上のフォルダーに置きます。セットアップ画面から直接選択することもできます。
4. **`Lilith-AI-Mod-1.0.0-Beta.4-Setup.exe`** を起動します。検出された Steam のゲームフォルダーを確認するか、`Lilith.exe` のあるフォルダーを手動で選択します。
5. 中国語・日本語の AI 音声をインストールするか選び、依存ファイルの取得元を確認します。初期設定は「オフラインのみ」です。
6. 「インストール開始」を押して完了を待ちます。使用中のファイルがある場合は、ゲームとコントロールセンターを終了して再試行してください。
7. 「コントロールセンターを開く」、または作成されたデスクトップの **Lilith AI MOD** ショートカットを使用します。モデル接続と各種設定を行い、Steam からゲームを起動して接続状態を確認します。

旧アーキテクチャー／クローズドテスト版からは上書き更新できません。先に下記の新規インストール準備を完了してください。

## 「オフラインのみ」の意味

これは**セットアップ時の依存ファイルの取得方法**です。既存の互換環境やローカル ZIP を使い、不足している依存ファイルをダウンロードしません。

**リモート AI モデルがオフラインで動作するという意味ではありません。** Gemini、DeepSeek などのリモートサービスには、引き続きネットワーク接続と各自の接続設定・認証情報が必要です。料金や制限は利用するサービスに従います。

AI 音声を選択していても、互換環境も依存 ZIP もなければ、オフライン設定では自動ダウンロードされません。依存 ZIP を指定するか、公式配布元・自動選択・清華大学ミラーなどのオンライン取得元へ切り替えてください。任意の AI 音声を外して、先にコア MOD をインストールすることもできます。

## コントロールセンターの起動

正式なデスクトップショートカットを使用してください。コントロールセンターがバックグラウンドサービスを起動するため、旧版の起動スクリプトや Runtime の手動起動は不要です。

実行ファイルの場所：

```text
<ゲームフォルダー>\BepInEx\data\LilithTextInjector\control-center\LilithControlCenter.exe
```

ショートカットを作り直す場合は、引用符で囲んだ実際のパスの後ろに **`--provider-live`** を付け、作業フォルダーを同じ `control-center` フォルダーにします。

```text
"<ゲームフォルダー>\BepInEx\data\LilithTextInjector\control-center\LilithControlCenter.exe" --provider-live
```

`<ゲームフォルダー>` は実際の場所に置き換えてください。正式なショートカットとセットアップの起動ボタンには、この引数が設定済みです。EXE の単独ダブルクリックとは動作条件が異なります。

## 旧アーキテクチャー／クローズドテスト版からの移行

以前の版はクローズドテスト用です。旧会話・記憶・設定を Beta.4 へ引き継いだり、旧バックアップをインポートしたりしないでください。通常のアンインストールはデータを残すため、それだけでは今回の準備は完了しません。

1. ゲームと旧コントロールセンターを、通知領域のものも含めて終了します。
2. Windows「設定 → アプリ」に旧 Lilith AI MOD があれば、先にアンインストールします。項目がなければこの手順は省略します。
3. `Win+R` から `%LOCALAPPDATA%` を開き、その中の **`LilithAiMod` フォルダーだけ**を削除します。`Local` 全体は削除しません。
4. Steam からゲームのローカルファイルを開き、**`BepInEx\data\LilithTextInjector` フォルダーだけ**を削除します。旧記憶がここにも残るため、AppData 側だけでは不十分です。
5. 同じゲームフォルダーにある旧設定 **`BepInEx\config\community.lilith.textinjector.cfg`** を削除します。指定の項目が存在しない場合は省略します。
6. Beta.4 を新規インストールし、モデル接続・認証情報・個人設定を設定し直します。**旧フォルダーの復元や旧会話／記憶のインポートはしないでください。**

これは旧 MOD の会話・記憶・設定をリセットするための必要な作業です。削除対象は指定したリリス専用の場所だけです。**システムの AppData／Local 全体、BepInEx 全体、他の MOD、ゲーム本体のセーブデータは削除しないでください。** 保存先を独自に変更していて判断できない場合は、実際のパスと診断を添えて管理者へ確認してください。

## 今後の新アーキテクチャー内の更新

今後、明確にデータ互換性が案内された更新に限り、新版のデータを引き継げます。この扱いを以前のクローズドテスト版に適用しないでください。エクスポート／インポートは対応する新版セーブ用で、非互換の旧記憶を移行する機能ではありません。

旧プログラムのロールバック用コピーは残りません。更新が中断された場合はアプリを終了し、セットアップを再実行してください。検証エラーは診断を保存して報告し、検証用の一覧を書き換えて回避しないでください。

## 困ったとき・アンインストール

- **ゲームが見つからない：** `Lilith.exe`、`GameAssembly.dll`、`Lilith_Data` のあるフォルダーを選択します。
- **オフライン依存 ZIP が見つからない：** フォルダーが一段深くなっていないか確認するか、画面から直接 ZIP を指定します。
- **ゲームバージョンが非対応：** パスを確認し、対応するセットアップを入手してください。ゲームの DLL を自己判断で差し替えないでください。
- **インストール後に音声の警告：** コントロールセンターの診断に従って確認します。音声の準備警告だけで、コア MOD 全体のインストール失敗とは限りません。
- **ファイル使用中／更新中断：** 両方のアプリを終了してセットアップを再実行します。

削除する場合は Windows「設定 → アプリ」で Lilith AI MOD を選択します。通常のアンインストールではデータと共用ファイルが残り、旧プログラムは復元されません。**旧アーキテクチャーから Beta.4 へ移る場合は、上記の専用データ削除も必要です。**
